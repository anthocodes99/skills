# anthocodes-skills

My collection of skills.

## Installation

### Platform Agnostic (Recommended)

Install into any agent that supports [agent skills](https://github.com/vercel-labs/skills):

```bash
npx skills add anthocodes99/skills
```

Pick the skills you want from the interactive list. They're installed as ordinary files you own and can edit.

### Claude Code

Install as a managed plugin that updates when I ship changes:

```bash
/plugin marketplace add anthocodes99/skills
/plugin install anthocodes-skills
```
